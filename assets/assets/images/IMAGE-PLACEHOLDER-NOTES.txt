## Image Optimization Guidelines

### Before Upload:
1. **Resize to appropriate dimensions**
   - Hero images: 1920x1080px or larger
   - About image: 800x1000px
   - Logo: 400x400px (displayed at 40x40px)

2. **Optimize file size**
   - Use tools like TinyPNG, Squoosh, or Photoshop "Save for Web"
   - Target: Hero images under 500KB, about image under 300KB
   - Logo: Under 50KB

3. **Format selection**
   - JPG for photographs (hero-1.jpg, hero-2.jpg)
   - PNG for logo (with transparency)
   - Consider WebP for better compression (with JPG fallback)

### Recommended Tools:
- **TinyPNG** (https://tinypng.com/) - Compress images
- **Squoosh** (https://squoosh.app/) - Advanced compression
- **Canva** - Create or edit logo if needed
- **Remove.bg** - Remove backgrounds from images

## Photography Style Guide

### DO:
✓ Use professional, high-quality photography
✓ Ensure good lighting (natural light preferred)
✓ Show attention to detail and craftsmanship
✓ Include clean, organized work environments
✓ Feature premium tools and materials
✓ Capture satisfied client interactions
✓ Show before/after transformations
✓ Include diverse property types (residential, estate)

### DON'T:
✗ Use stock photos that look generic
✗ Include cluttered or messy workspaces
✗ Show budget or low-quality tools
✗ Use dated or poor-quality images
✗ Include watermarks or copyright text
✗ Use images with visible competitor branding
✗ Show unsafe work practices
✗ Include recognizable people without permission

## Image Placement Instructions

### Step 1: Prepare Your Images
1. Rename your images exactly as shown:
   - `hero-1.jpg`
   - `hero-2.jpg`
   - `logo.png`

2. Optimize images using recommended tools

3. Verify file sizes are reasonable

### Step 2: Add to Project
1. Place images in: `/assets/images/` folder
2. Ensure exact file names match
3. Check file extensions (jpg vs jpeg)

### Step 3: Test
1. Open `index.html` in browser
2. Verify all images load correctly
3. Check responsive behavior on mobile
4. Ensure images look sharp on retina displays

## Image Aspect Ratios

**Hero Background (hero-1.jpg):**
- Desktop: 16:9 ratio (1920x1080px)
- Will be cropped on mobile to fill screen
- Keep important content centered

**About Image (hero-2.jpg):**
- Vertical or square orientation
- 4:5 ratio works well (800x1000px)
- Should complement text content

**Logo (logo.png):**
- Square (1:1 ratio)
- Transparent background
- Vector or high-res raster
